TREINO A — PWA

O PWA funciona como aplicativo no Android e pode ser adicionado à tela inicial.

Para publicar:
1. Hospede estes arquivos em um endereço HTTPS (GitHub Pages, Netlify, Vercel etc.).
2. Abra o endereço no Chrome Android.
3. Use o menu do Chrome e escolha "Adicionar à tela inicial" ou "Instalar aplicativo".
4. O app abrirá em modo de aplicativo.

Os dados ficam salvos no armazenamento local do navegador.
